# 🎓 CGPA & GPA Calculator

A simple and interactive **GPA & CGPA Calculator** built with **HTML, CSS, and JavaScript**.  
This app allows students to easily calculate their **Grade Point Average (GPA)** and **Cumulative Grade Point Average (CGPA)** with a clean and responsive interface.

---

## 📖 About
The CGPA Calculator helps students keep track of their academic performance by:  
- Entering course units and grades  
- Instantly calculating **semester GPA**  
- Updating and displaying **overall CGPA**  

It’s fast, lightweight, and works on any modern browser.  

---

## ✨ Features
- ✅ GPA calculation based on grades and course units  
- ✅ CGPA calculation across multiple semesters  
- ✅ Responsive design (mobile & desktop friendly)  
- ✅ Built entirely with **HTML, CSS, and Vanilla JavaScript**  
- ✅ No frameworks required – works offline
